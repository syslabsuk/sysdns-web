Manifesto

Plaintext DNS is a broadcast.

Port 53 tells every hop on the path what a device is about to open. sysdns replaces that with one authenticated tunnel per device: the resolver runs locally, collapses concurrent identical lookups into a single upstream call, and forwards only what it can't already answer.

No plaintext queries on the wire. No shared credential doing everything. No resolver you don't run.

Architecture

Three components. One path.

01 / agent

Runs on the device

A caching, forwarding resolver on UDP and TCP. Answers from an in-memory TTL/LRU cache, otherwise forwards over DNS-over-QUIC to a pool of relays it round-robins across.

02 / backend

Relays and enforces

Terminates mTLS DoQ from roaming agents, answers from a large shared cache, and forwards the rest upstream — applying the per-agent and per-group blocklist and whitelist on the way through.

03 / admin

Holds the credential

Operators never touch the admin mTLS key. This server holds it, proxies every action, and records who did what — the only place individual-operator attribution exists.

Policy

Blocklists that follow the device.

Group agents, attach blocklists and whitelists, and move a device between groups without touching the device. Policy lives in the relay, so a laptop on hotel wifi gets the same answers it gets at a desk.

Every mutating action — group created, domain added, agent reassigned — lands in the audit log with the operator, the target and the timestamp.

Enrollment

One token. Then a key that never travels.

An operator mints a registration token; the device presents it once. The agent generates its own ECDSA P-256 keypair locally, submits a CSR, and persists the signed certificate at 0600. The private key is never transmitted, and subsequent runs skip registration entirely.

Group-scoped

Multi-use. Enrolls any number of devices straight into the chosen group.

Targeted

Single-use. The first device wins; a concurrent race has exactly one winner.

Observability

Every answer, accounted for.

Resolution metrics roll up by source — a registered agent or a direct client address — and drill down to individual lookups with the domain, the verdict and where the answer came from.

Scale

Add relays, not migrations.

Run as many relay instances as you need against one shared policy store. Each keeps a fast in-memory read cache of that policy; agents already round-robin across whichever instances they're pointed at, so capacity is a deployment decision, not a rewrite.

Take DNS off the wire.

Self-hosted, three binaries, one Postgres. Early access is open to teams running their own infrastructure.
